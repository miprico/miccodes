Crea tu página web
de emprendimiento con IA

Aprenderás a usar inteligencia artificial para construir una página web real para tu negocio, entender el código que genera y publicarla en internet.

5 sesiones · 2 horas c/u
Individual o parejas
VS Code · ChatGPT · Netlify
ABP · Pensamiento computacional
1
¿Qué vas a aprender?

Programación web básica

Entender la función de HTML, CSS y JavaScript leyendo y modificando código real.

Uso crítico de la IA

Usar la IA como herramienta, no como respuesta: saber cuándo te ayuda y cuándo se equivoca.

Emprendimiento digital

Crear y publicar un producto digital real con una propuesta de valor clara.

Comunicación digital

Presentar tu proyecto con un pitch de 2 minutos frente a compañeros y docentes.

2
¿Qué vas a entregar al final?

Página web publicada

Con URL real que cualquiera puede abrir desde su celular o computador.

Bitácora de IA

Registro de los prompts que usaste, qué cambió la IA y qué modificaste tú.

Pitch de 2 minutos

Presentas tu negocio, mostrás la web en vivo y explicás una decisión que tomaste tú.

Análisis crítico

Respondes: ¿en qué se equivocó la IA? ¿qué tuviste que corregir vos?

3
Secuencia de sesiones
1

Exploración — ¿Por qué tu negocio necesita una web?

Conoces la estructura básica de HTML y defines tu emprendimiento

2 horas
Inicio · 20 min
  • El docente muestra 3 páginas reales de emprendimientos locales. Votan: ¿cuál vende más y por qué?
  • Pregunta detonadora: "Si tu vecina vende arepas, ¿cómo le consigo 50 clientes nuevos sin tener local?"
  • Lluvia de ideas: ¿qué elementos tiene una página web? ¿qué la hace atractiva?
Desarrollo · 70 min
  • Mini clase (15 min): HTML = paredes de la casa · CSS = pintura y decoración · JS = puertas que se abren
  • Abrís un archivo hola.html en el bloc de notas, escribís 5 etiquetas a mano y lo abrís en Chrome
  • Completás tu Ficha del emprendimiento: nombre del negocio · producto o servicio · cliente ideal · colores de tu marca
  • Primer prompt libre a la IA: generás solo el encabezado de tu página y lo analizás
Prompt de la sesión 1
Actúa como profesor de programación web. Genera solo el encabezado HTML para mi negocio llamado "[NOMBRE DE TU NEGOCIO]". Después explícame en 3 líneas qué hace cada etiqueta. Dime también qué debo cambiar para personalizar el color y el tamaño del texto.
Cierre · 10 min
  • Cada uno comparte en voz alta: nombre de su negocio y color de marca elegido
Para la próxima sesión
  • Traer 3 fotos del producto (pueden ser tomadas con el celular o buscadas en internet)
  • Tener listos: nombre del negocio, descripción en 2 líneas, precio de 3 productos
2

Construcción — Generamos la página completa

Usás el prompt principal y tenés tu primera versión funcional

2 horas
Prompt principal · 30 min
Prompt completo (completá los campos en [ ])
Actúa como desarrollador web profesional. Crea UNA página web completa en un solo archivo HTML para un emprendimiento llamado "[NOMBRE]" que vende [PRODUCTO]. REQUISITOS OBLIGATORIOS: - Colores principales: [color 1] y [color 2] - Sección hero con título y subtítulo llamativo - Sección con 3 productos o servicios con precio - Sección "¿Por qué elegirnos?" con 3 razones - Formulario de contacto (nombre, email, mensaje) - Botón de WhatsApp flotante con número [NÚMERO] - Al hacer clic en "Comprar" mostrar mensaje de confirmación - Diseño responsive (que se vea bien en celular) - Comentarios en el código explicando cada sección IMPORTANTE: Usa solo HTML, CSS y JavaScript. Sin frameworks externos. Todo en un solo archivo.
Proceso · 80 min
  • Copiás el código generado y lo pegás en VS Code o Bloc de notas
  • Guardás el archivo como index.html y lo abrís en Chrome
  • Anotás en la bitácora: ¿qué funciona? ¿qué no funciona? ¿qué quiero cambiar?
  • Si algo no funciona, usá el prompt de depuración (abajo)
Prompt para errores: "Tengo este error: [copiá el error]. El código es: [pegá el código]. ¿Qué está mal y cómo lo corrijo paso a paso?"
3

Personalización — La IA genera, vos decidís

Modificás el código para que la página sea realmente tuya

2 horas
Prompts de personalización
// Para cambiar colores: Cambia el color #1a1a1a por #[nuevo color] en todo el CSS. Explica qué cambiaste. // Para agregar animación: Agrega una animación suave de entrada al título principal cuando cargue la página. Solo CSS. // Para calcular descuento: Agrega un botón "Oferta especial" que al hacer clic muestre el precio con 10% de descuento calculado con JavaScript. Muestra el precio original tachado.
Reto de la sesión
  • Agregá al menos 1 función JavaScript que no estaba en el código original (sin pedírsela a la IA)
  • Modificá la paleta de colores usando solo CSS — sin pedirle ayuda a la IA esta vez
  • Completá la bitácora: ¿qué le pediste a la IA? ¿qué modificaste vos solo?
La IA a veces inventa colores que no existen, genera imágenes con URLs que no cargan o escribe texto que no tiene sentido para tu negocio. Siempre revisá que el contenido sea real y correcto.
4

Publicación — Tu página sale al mundo

Publicás tu página con una URL real y hacés revisión entre pares

2 horas
Cómo publicar gratis (sin código)
  • Opción A — Netlify Drop (más fácil): entrá a netlify.com/drop → arrastrá tu carpeta con el archivo → ¡URL lista en 30 segundos!
  • Opción B — GitHub Pages: creá cuenta en github.com → nuevo repositorio → subí index.html → activá Pages en Settings
  • Enviá la URL al docente y abrí la página desde tu celular para verificar que se vea bien
Revisión entre pares · 30 min
  • Intercambiás URL con un compañero y completás la ficha de retroalimentación:
  • ✅ Una cosa que funciona muy bien en su página
  • 🔧 Una cosa que mejorarías
  • ❓ Una pregunta sobre su negocio que la página no responde
5

Feria digital — Pitches y reflexión crítica

Presentás tu proyecto y reflexionás sobre el rol de la IA en tu aprendizaje

2 horas
Pitch · 2 minutos por equipo
  • Nombre del negocio y a quién va dirigido
  • Mostrás la página en vivo (desde el celular o el computador)
  • Una cosa que decidiste vos (no la IA)
  • Una cosa que aprendiste que no sabías antes
Reflexión final · 30 min
  • ¿Qué partes del código entendés ahora que antes no entendías?
  • ¿En qué se equivocó la IA? (errores, textos inventados, imágenes que no cargaron)
  • ¿La IA hizo todo el trabajo o vos tomaste decisiones? ¿Cuáles?
  • Debate: "¿Aprendiste programación o aprendiste a usar una herramienta?"
4
Niveles de trabajo
Nivel básico
  • Usás el prompt completo sin modificarlo
  • Solo cambiás textos e imágenes
  • Publicás con Netlify Drop
  • Bitácora: describís qué hizo la IA
Nivel avanzado
  • Agregás una sección nueva sin pedírsela a la IA
  • Modificás el JS para calcular precios dinámicamente
  • Conectás el formulario a Formspree (recibe emails reales)
  • Bitácora: explicás qué hace cada función del JS
